# FINANCASPro — Gestão Financeira Pessoal

Aplicação web desenvolvida para centralizar o controle financeiro pessoal, automatizar a organização de movimentações e permitir o acesso aos dados em diferentes dispositivos.

## Funcionalidades

- **Gestão financeira:** registro e organização de receitas, despesas, gastos fixos, dívidas e investimentos.
- **Controle de cartões:** acompanhamento de despesas no crédito, compras parceladas e compromissos financeiros.
- **Histórico mensal:** fechamento de períodos e preservação de registros financeiros para consulta posterior.
- **Sincronização em nuvem:** integração com Supabase para manter os dados disponíveis entre computador e celular.
- **Backup de dados:** exportação das informações financeiras em JSON para recuperação e preservação dos registros.

## Desenvolvimento e tecnologias

- **HTML, CSS e JavaScript:** estrutura, interface e lógica de funcionamento da aplicação.
- **Supabase:** autenticação de usuários e armazenamento remoto dos dados financeiros.
- **IndexedDB:** armazenamento local das informações no navegador.
- **Netlify:** hospedagem e disponibilização da aplicação web.

## Arquitetura da aplicação

A aplicação utiliza armazenamento local para trabalhar com os dados no navegador e integração com o Supabase para persistência em nuvem. A sincronização permite compartilhar informações entre dispositivos, enquanto os mecanismos de exportação e histórico auxiliam na preservação dos registros.

## Objetivo do projeto

Desenvolver uma solução prática para gestão financeira pessoal, integrando armazenamento local, serviços em nuvem e automação de rotinas para melhorar a organização, a disponibilidade e a segurança dos dados.

## Competências demonstradas

Desenvolvimento web, integração de APIs, modelagem e persistência de dados, automação de processos e resolução de problemas técnicos.
